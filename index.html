About CDL Lisence

Your virtual CDL operations desk

Road Authority turns supported ATS and ETS2 telemetry into a private, fictional driver record. It brings fines, cargo, fuel activity, collision reviews, CDL status, and simulated compliance rules together in one dashboard.

Getting started

Four steps to connect

  1. 01
    Close both games

    Exit ATS and ETS2 before installing so their plugin folders can be updated safely.

  2. 02
    Run the installer

    CDL Lisence detects your Steam libraries and installs the native plugin into each supported game it finds.

  3. 03
    Start a profile

    Launch one game and load a driver profile. The status at the top changes when live telemetry begins.

  4. 04
    Keep this site open

    The browser reads the local plugin, imports new activity once, and updates your reports automatically.

First-time walkthrough

Install and verify the connection

  1. 1
    Download the official installer

    Use the Download CDL Lisence button on this site. The installer supports 64-bit Steam installations of American Truck Simulator and Euro Truck Simulator 2.

  2. 2
    Exit ATS and ETS2

    Close both games completely before installation. This lets the installer safely add or update the telemetry plugin.

  3. 3
    Run CDL-Lisence-Setup.exe

    Approve the Windows administrator prompt. Windows may show SmartScreen because the installer is not code-signed; only continue with the file downloaded from this official project.

  4. 4
    Confirm the detected games

    The installer searches your default and additional Steam libraries, then installs CDL Lisence.dll into every supported game it finds. No manual folder selection is needed.

  5. 5
    Launch one game

    Start ATS or ETS2. If the game displays an SDK or telemetry notice, acknowledge it; that notice is expected when a telemetry plugin is installed.

  6. 6
    Load your game profile

    At the game menu, this site reads ATS/ETS2 open · select profile. Select a driver and enter the game world; the status then changes to your configured driver name and online.

Configure the simulation

Set up your CDL Profile

Driver name

Enter the fictional name displayed on your in-game CDL, dashboard, and online connection status.

Home state

Choose Oklahoma to enable its point cycle and suspension rules. Other states retain the federal simulation without an active state rules pack.

Class and endorsements

Select the CDL class and H, N, P, S, T, or X endorsements you want shown on the fictional credential.H = Hazardous materials · N = Tank vehicles · P = Passengers · S = School buses · T = Double/triple trailers · X = Tank vehicles and hazardous materials

Medical expiration

Set the certificate date. Passing the selected game date changes the dashboard status to Not Certified.

Gameplay cash

Enter the balance available for paying gameplay fines from the Driver Record. This does not change money inside ATS or ETS2.

Defensive-driving date

An eligible course dated after the latest point event removes two points from the simulated Oklahoma balance.

Prior point suspensions

Enter earlier Oklahoma point suspensions so the next simulated action uses the correct 30, 90, 180, or 365-day sequence.

Strict enforcement mode

On applies active federal and Oklahoma sanctions to the CDL status. Off reports the same calculated actions as advisories.

Finish with Save profile

Your selections are stored locally in this browser and immediately update the dashboard and in-game CDL preview.

Connection help

If the site still says Game offline

01

Confirm ATS or ETS2 is running. The website cannot connect while both games are closed.

02

Close the game, rerun the latest official installer, and then restart the game. Updates can replace plugin files.

03

Verify CDL Lisence.dll exists in the game’s bin\win_x64\plugins folder.

04

Run only one supported game at a time because ATS and ETS2 share the same local telemetry port.

05

Use this official GitHub Pages site. The local bridge rejects unrelated website origins for privacy.

06

If the status says open · select profile, installation succeeded; load a driver profile and enter the game world.

Under the hood

How the connection works

ATS or ETS2Produces game telemetry
CDL Lisence pluginCaptures supported events
Local bridgeRuns at 127.0.0.1
Road AuthoritySaves reports in your browser

From the game

Captured automatically

  • Connection and profile status

    Shows which supported game is open and whether a driver profile is actively sending telemetry.

  • Official gameplay fines

    Imports SCS fine events once and preserves events captured while the website was closed.

  • Accepted cargo jobs

    Records cargo, route companies and cities, planned distance, and expected payout.

  • Fuel quantity and location

    Combines confirmed tank increases into fill-ups and records game-world coordinates.

  • Possible collision damage

    Detects sudden vehicle damage and asks you to confirm whether traffic was involved.

From the driver

You review or enter

  • Fuel-stop location

    The site records game-world coordinates automatically. You may add a private location label, but no unverifiable price or spending claim is stored.

  • Collision confirmation

    Damage alone cannot prove a traffic collision. You decide whether a pending report is created.

  • Case outcome and details

    Choose pending, convicted, or dismissed and add gameplay fines, points, and notes when needed.

  • Fictional CDL profile

    Set the name, home state, class, endorsements, medical date, and enforcement preferences.

  • Simulation date

    The selected game date controls rolling rule windows, medical status, and simulated sanctions.

Privacy

Local first, cloud optional

Your profile, incidents, fuel history, cargo history, and learned stations stay in this browser unless you sign in and enable companion record sync. The plugin also keeps captured fine events in your game Documents folder so they can be recovered after a restart.

Without an account, only an anonymous random session ID and the active game are sent for the community counter. With an account, the companion record is stored in the project database so it can load in another browser. Discord or Steam authenticates identity only; neither provider supplies game telemetry, saves, or passwords.

Use Export record for a backup before clearing browser data or moving to another browser, then use Import record to restore it.

Important limits

What this is not

This is a fictional gameplay companion. It is not legal advice, an official driving record, a government service, or a substitute for current laws and agency guidance.

Collision detection is an informed damage signal, not a direct SCS collision event. SCS does not expose fuel price or payment, so Fuel Report records quantity and location only. Cargo value means the game's expected job payout.

The plugin supports SCS telemetry API 1.x minor revisions. A future incompatible 2.x API or game architecture change may require an updated plugin.
